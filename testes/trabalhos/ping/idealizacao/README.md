# Protótipo arquivado do Trabalho 1

Esta pasta guarda uma implementação inicial sobre alertas de rede, movida para `testes/trabalhos/ping/idealizacao/` como material de referência. Ela é separada do Trabalho 1 atual, documentado em [trabalhos/trabalho1](../../../../trabalhos/trabalho1/README.md).

O protótipo contém modelos `Ataque` e `RelatorioIncidente`, serviços, streams, comunicação cliente-servidor por TCP e uma implementação de notificações UDP multicast. A questão extra de votação não foi implementada nesta cópia.

As instruções antigas usavam o nome de pacote `trab1_v2`, que não existe neste repositório. Por isso, este README descreve o conteúdo preservado sem repetir aqueles comandos.
