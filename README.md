# Sistemas Distribuídos

Repositório com exercícios e trabalhos da disciplina.

## Trabalhos

- [Trabalho 1](trabalhos/trabalho1/README.md): comunicação entre processos com streams, request/reply TCP, notificações multicast e votação. `trabalho1` é a versão final consolidada a partir de `trab_v1`.
- [Trabalho 2](trabalhos/trabalho2/README.md): biblioteca remota com RPC/XML-RPC e notificações por consultas periódicas.
- [Trabalho 3](trabalhos/trabalho3/README.md): sistema de biblioteca com API FastAPI, clientes Java e Node.js e notificações RabbitMQ.
